mend is one patch tool for every AI edit format: it reads a unified diff, SEARCH/REPLACE blocks, a V4A patch or JSON edits, finds the lines each edit names even when the model drifted their whitespace or indentation, and changes every file or none. See SPEC.md for the whole contract.

## Run it

```sh
node main.ts [options] [PATCH]
```
